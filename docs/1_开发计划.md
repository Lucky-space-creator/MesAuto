# MES Core 开发计划

## 一、项目概述

在现有 `lins_mes` 工业 MES 基础上，抽取核心主流程，重构为轻量级、可独立运行的 **mesCore** 系统。聚焦制造执行核心链路，剔除外部系统集成（ERP/AGV/PLC/APS），保留企业级基础能力。

---

## 二、技术选型

| 技术 | 版本 | 用途 |
|------|------|------|
| Spring Boot | 4.1.0 | 基础框架 |
| MyBatis-Plus | 3.5.9 | ORM / 分页 / 代码生成 |
| MySQL | 8.0+ | 关系型数据库 |
| Redis | 7.x | 缓存 / 分布式锁 / 会话 |
| Shiro | 2.x (Jakarta) | 认证授权 / RBAC |
| ShardingSphere-JDBC | 5.5.x | 分库分表 |
| MinIO | 8.x | 对象存储（Excel / 附件） |
| Activiti | 8.x | 审批工作流（可选，默认使用自研轻量审批引擎） |
| EasyExcel | 4.x | 导入导出 |
| Hutool | 5.8.x | 通用工具 |
| Knife4j | 4.x | API 文档 |

## 五、订单全生命周期状态机

```
  [创建]
    │
    ▼
  草稿(DRAFT) ──编辑──→ 草稿
    │
    │ 提交审批
    ▼
 审批中(APPROVING) ──驳回──→ 草稿
    │
    │ 通过
    ▼
 已下达(RELEASED)
    │
    │ 排程拆解
    ▼
 生产中(IN_PRODUCTION)
    │
    │ 生产完成 + 入库完成
    ▼
 已完成(COMPLETED)
    │
    ▼
 已关闭(CLOSED) ── 终止态，不可逆
```

> **说明**：
> - **七种持久状态**：`DRAFT` / `APPROVING` / `RELEASED` / `IN_PRODUCTION` / `PENDING_STORAGE` / `COMPLETED` / `CLOSED`
> - `PENDING_STORAGE`（待入库）：生产中所有任务报工完成、但入库尚未完成的中间态，入库全部完成后自动跳转 `COMPLETED`
> - "排程中"、"生产完成" 为**瞬时动作**，不单独作为持久状态，计入 `RELEASED`/`IN_PRODUCTION` 的上下文中
> - 只有 `DRAFT`、驳回后的草稿可编辑；`CLOSED` 为终态不可逆
